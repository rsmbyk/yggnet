# Communication

- Asks "why is it X?" about constants, formulas, and behavior and expects the rationale/derivation explained, in plain language up to "explain like I'm 5". Confidence: 0.85
- Writes short, lowercase, fragmentary requests — often several bullets in one message — and expects intent to be inferred, asking the agent to clarify when something is ambiguous. Confidence: 0.7
- Reports symptoms as observed behavior and expects the agent to diagnose the cause (e.g. "why do I feel like the whole world is re-drawn?") rather than being handed a fix recipe. Confidence: 0.65
